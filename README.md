# TradeBuddy Trust Website

A responsive static website for `gettradebuddy.app`.

## Files
- `index.html` — homepage
- `about.html` — About TradeBuddy
- `help.html` — Help Center
- `contact.html` — Contact Support
- `terms.html` — Terms of Service
- `privacy.html` — Privacy Policy
- `refund.html` — Refund & Cancellation Policy
- `delete-account.html` — public account-deletion page
- `styles.css` — responsive design system
- `script.js` — small interactions
- `assets/favicon.svg` — temporary favicon/logo mark

## Deploy
This is a static site. It can be deployed to Cloudflare Pages, Netlify, Vercel, GitHub Pages, or Lovable.

### Cloudflare Pages
1. Create a new Pages project.
2. Upload this folder or connect a Git repository.
3. Build command: leave empty.
4. Output directory: `/`.
5. Attach the custom domain `gettradebuddy.app`.

## Before launch
- Replace the temporary logo mark with the final TradeBuddy logo if desired.
- Add real App Store and Google Play links.
- Connect the account-deletion form to the secure backend flow.
- Replace `admin@gettradebuddy.app` with `support@gettradebuddy.app` once the alias is active.
- Insert final legal entity and governing jurisdiction.
- Have Terms and Privacy reviewed by a qualified attorney.
